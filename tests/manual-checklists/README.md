# Manual Test Checklists — JejakBahari

Checklist untuk manual testing dan exploratory testing per sprint. Sesuai `16_TESTING.md` §8.

## Struktur

```text
tests/manual-checklists/
├── README.md
├── checklist-template.md
├── sprint-3-map.md
├── sprint-4-search.md
└── ...
```

## Cara Menggunakan

1. Duplikasi `checklist-template.md` untuk setiap sprint/fitur.
2. Jalankan checklist secara manual di browser.
3. Catat hasil: PASS / FAIL / BLOCKED.
4. Jika FAIL, buat bug di JIRA dan catat Bug ID.
5. Update `docs/qa/TRACEABILITY_MATRIX.md`.
