# 11 — Feature Roadmap

## Phase 0 — Foundation

- Repository structure.
- Documentation.
- CI baseline.
- Local environment.
- Database migrations.

## Phase 1 — MVP Core

- Vessel registry.
- AIS worker connection.
- Latest positions API.
- Public map.
- Search dan detail.
- Freshness.
- Admin CRUD.
- Basic deployment.

## Phase 2 — Operational Context

- History 24 jam.
- Ports dan routes.
- Geofence arrival/departure.
- Worker health dashboard.
- Realtime push.

## Phase 3 — Community

- Public data contribution workflow.
- Evidence review.
- Source attribution pages.
- Data quality dashboard.
- Import/export registry.

## Phase 4 — Reliability

- Multiple AIS providers.
- Receiver AIS integration.
- Managed database.
- Redis queue/cache.
- History partitioning.
- Monitoring dan alerting.

## Phase 5 — Optional Enhancements

- Favorite.
- Notification.
- ETA heuristik.
- Weather overlay.
- Public API with API keys.

Setiap fase harus melalui review PRD dan ADR sebelum dimulai.
